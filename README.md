# arabity-data

بيانات جداول الصيانة لتطبيق «عربيتي». التطبيق بيحمّل الملف `schedules.json` من هنا ويحدّث فترات الصيانة لكل موديل.

- `version`: زوّده بواحد مع كل تعديل عشان التطبيقات تعرف إن فيه تحديث.
- كل جدول فيه `match` (الموديل والمحرك والسنين)، و`items` (الفترات بالكيلومتر)، و`sources` (المصادر).
- البنود اللي مش موجودة في جدول الموديل بتفضل على التقدير العام في التطبيق.
